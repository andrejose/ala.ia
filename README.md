# ala.ia

API REST para um sistema de controle financeiro pessoal.

**ALA** = **A**utonomia, **L**iberdade e **A**utocontrole — conquistar liberdade financeira por meio do conhecimento e da organização dos gastos.

## Escopo (MVP)

Controle de gastos de forma simples e eficiente. Requisitos funcionais mínimos em definição.

## Stack

| Área         | Tecnologia                                 |
| :----------- | :----------------------------------------- |
| Backend      | Next.js                                    |
| Database     | PostgreSQL, MySQL ou SQLite (em definição) |
| Testes       | Vitest                                     |
| Documentação | Swagger                                    |
